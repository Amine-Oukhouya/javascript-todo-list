# JavaScript ToDo List

A simple, responsive ToDo List built with HTML, CSS, and vanilla JavaScript.

## Features
- Add new tasks
- Delete tasks
- Mark tasks as completed
- Persist tasks using browser localStorage

## Technologies
- HTML5
- CSS3
- JavaScript (DOM manipulation, event handling, localStorage)

## Getting Started
Clone the repository and open `index.html` in your browser.

## What I Learned
This project helped me practice DOM manipulation, event handling, array operations, and browser storage.
